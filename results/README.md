# Results

`final_metrics.json` records the values reported in the final extended abstract.
`owner_classification.csv` contains the ResNet18 and MobileNetV3-Small comparison.

The qualitative figure shows representative full-pipeline outcomes: correct category and
owner predictions, a correctly rejected unknown object, false-positive detections, and an
owner error. It is included for error analysis rather than as a substitute for the test
metrics.

The older `training_logs/` files document exploratory detector runs. Those runs used
earlier datasets and should not be interpreted as the final comparison.
