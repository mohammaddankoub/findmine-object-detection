# Results

`experiment_summary.csv` reports the best validation epoch selected by mAP50 for
each completed run. The raw Ultralytics CSV files are kept in `training_logs/` so
the summary can be regenerated.

The prediction contact sheet is a qualitative review of held-out capture sessions.
It shows several correct detections, missed objects, and false positives. It should
not be interpreted as a final test metric.
